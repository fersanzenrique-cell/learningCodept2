- Un **[[Programas, ejecutables, procesos y servicios#^3d25de|Programa]]** realiza las operaciones deseadas con los datos necesarios.
- Los Datos son los elementos con los que opera un programa. Esos datos pueden ser obtenidos por el programa mediante diversos métodos: leídos mediante teclado, escaneados, leídos de algún soporte de almacenamiento secundario, etc.
	- Almacenamiento primario o memoria principal. Dónde se almacenan los datos con los que en cada momento está trabajando el programa.
		✓ Volátil. Sus contenidos se borran cuando se apaga el ordenador.
		✓ Capacidad relativamente baja.
		✓ Rápida. Tiempo de acceso a los datos corto.
	- Almacenamiento secundario. Dónde se almacenan los datos de manera permanente.
		✓ Permanente. Sus contenidos NO se borran cuando se apaga el ordenador.
		✓ Capacidad relativamente alta.
		✓ Lenta. Tiempos de acceso relativamente altos.
